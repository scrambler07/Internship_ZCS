## 🚀 Overview

During this internship, I worked across multiple domains in electronics, combining **theoretical learning with practical exposure**. The program covered PCB design, embedded systems, firmware basics, and real-world product development processes.

---

## 🛠️ Key Areas of Work

* **PCB Design:**
  Designed schematics and layouts using **OrCAD and Allegro**, including component placement and routing

* **Embedded Systems:**
  Studied system architecture and interaction between **hardware and firmware**

* **Communication Protocols:**
  Worked with **UART, SPI, and I²C** for data communication

* **Electronics Fundamentals:**
  Explored **voltage regulators** (linear and switching) and their applications

* **Hardware Skills:**
  Performed **manual soldering** and used instruments like **oscilloscope and function generator**
